# Company Management System

## Description
Console application built using C# and SQL Server to manage employees.

## Features
- Login System
- Add Employee
- View Employees
- Search Employee
- Update Employee Data
- Delete Employee

## Technologies
- C#
- .NET 9
- SQL Server
- Microsoft.Data.SqlClient

## Database
The application uses SQL Server database with:
- Employees table
- Departments table

## Concepts Practiced
- ADO.NET
- SQL Queries
- CRUD Operations
- Parameterized Queries
- Input Validation
- Exception Handling

Update connection string before running the project.
